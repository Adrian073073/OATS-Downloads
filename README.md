# OATS Downloads

OATS is a dependency-free Windows desktop automation manager.

## Install

1. Open the [latest release](https://github.com/Adrian073073/OATS-Downloads/releases/latest).
2. Download `OATS-Manager-<version>-windows-x64.zip`.
3. Select **Extract all** in Windows.
4. Open the extracted `OATS-Manager` folder and double-click **Install OATS.vbs**.
5. Open **OATS Manager** from the desktop or Start menu and install only the automations you want.

No administrator rights, Python, pip, Git, GitHub account, access token, or dependency installation is required.

OATS verifies the exact size and SHA-256 of every Manager and automation download before activation. Installed automations and retained settings stay under `%LOCALAPPDATA%\OATS` when the Manager is updated or uninstalled.

Source development is maintained separately. This public repository contains only recipient-facing release downloads.
